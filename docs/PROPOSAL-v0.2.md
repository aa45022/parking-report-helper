# 第二版改善提案（v0.2 以後）

> 日期：2026-10-17
> 依據：使用者實際測試 v0.1 後的回饋

---

## 1. 你遇到的問題和原因

| 問題 | 原因 | 處理方式 |
|---|---|---|
| 找不到「個人資料」等功能 | 分頁列放在畫面最下方，在 Claude 的頁面裡可能被擋住，或要捲到最底才看得到 | ✅ v0.1.1 已改到最上方，並加上「先設定個人資料」提醒 |
| 按「開啟桃園市檢舉網站」沒反應 | Claude 頁面開外部連結的限制比較多；桃園網址帶有特殊埠號 `:3444`，有些網路或 App 打不開 | ✅ v0.1.1 已加上「複製網址」，可以貼到 Safari 開 |
| **不能自己抓定位** | Claude 的私人頁面（Artifact）是安全沙盒。**你的帳號目前沒有開放「定位」和「相機」權限給頁面使用**，頁面也不能連到外部的地址查詢服務。這是 Claude 平台的限制，不是程式寫錯 | 見第 2 節 |
| 整體體驗不夠好 | 所有步驟擠在一個很長的頁面；沒有首頁；沒有新手引導 | 見第 3 節的改版設計 |

## 2. 定位問題的兩條路

### 路線 A：繼續在 Claude 裡測試，用替代方法取得地點

| 方法 | 怎麼做 | 效果 |
|---|---|---|
| 照片定位 | 選照片時點「選項」，打開「位置」 | 可以取得縣市、行政區（v0.1 已有） |
| **附近的舊案件** | 如果這個 GPS 位置 50 公尺內你以前檢舉過，自動帶入當時的路名和門牌 | 常檢舉同一區的人越用越準 |
| **常用地點** | 把家附近、通勤路線的地點存起來，下次一鍵選 | 不用每次打字 |
| **貼上地圖位置** | 在 Apple 地圖點自己的位置 →「分享」→「拷貝」，回到 App 貼上 | 可以拿到座標，有時也有地址（要實測） |
| Claude 讀路名牌 | 拍全景時拍到路名牌或門牌 | v0.1 已有 |

- 優點：今天就能用，不用另外申請任何帳號。
- 缺點：還是**不能即時定位、不能在 App 裡開相機**，路名也不一定能自動查到。

### 路線 B：改成「只有你能登入的私人網站」

把同一個 App 放到自己的網站上，例如 Cloudflare Pages。再用 Cloudflare Access 設定**只有你的 Email 能登入**，別人打不開。

| 能力 | Claude 頁面（現在） | 私人網站 |
|---|---|---|
| 即時定位 | ❌ | ✅ 打開就知道你在哪 |
| App 內相機 | ❌ | ✅ 拍照當下記錄 GPS，並在照片壓上日期、時間、地點 |
| 自動查路名和門牌 | ❌ | ✅ 用國土測繪中心等服務查詢 |
| 開啟官方網站 | 有時不行 | ✅ 正常 |
| 加到主畫面像 App 一樣用 | 部分 | ✅ |
| 讀車牌 | ✅ 用你的 Claude 帳號 | 要改用 Claude API（每張約 0.005 元台幣，先儲值 US$5 可以用很久），或用手機上的免費模型 |
| 私人 | ✅ | ✅ 只有你的 Email 能登入 |
| 費用 | 0 | 0（Cloudflare 免費方案），讀車牌另計 |
| 你要做的事 | 不用做 | 申請免費 Cloudflare 帳號，並照我的步驟設定一次（約 15–20 分鐘） |

### 建議

**兩條都走，分先後：**
1. **先做 v0.2（路線 A）**：在 Claude 裡把介面改好、加上新功能，馬上可以用。
2. **再做 v0.3（路線 B）**：搬到私人網站，從根本解決定位和相機。

程式碼大部分可以共用，不會白做。

## 3. 新的使用體驗設計

### 3.1 設計原則

1. **一個畫面只做一件事**：不再用一長串頁面，改成「上一步／下一步」，並顯示進度（例如 2/5）。
2. **打開就知道要做什麼**：首頁有一個大按鈕「我看到違停」，再加上待辦清單。
3. **在路邊單手可以操作**：大按鈕、大字、高對比；重要按鈕放在手指搆得到的位置。
4. **系統先猜，你只要確認**：能自動判斷的都先填好，標示「自動」，你只要看過、不對再改。
5. **每一步都告訴你為什麼**：例如「為什麼要拍駕駛座？警方要看車上有沒有人，才能判斷是停車還是臨停」。

### 3.2 新的畫面架構

```
┌ 首頁 ────────────┐  ┌ 檢舉流程（5 步）┐  ┌ 紀錄 ──────────┐  ┌ 我的 ──────────┐
│ ［我看到違停］大鈕│  │ 1 判斷能不能檢舉 │  │ 草稿／已送出／結果│  │ 個人資料        │
│ 待辦：2 件快到期  │→ │ 2 拍照與照片     │  │ 搜尋車牌        │  │ 常用地點        │
│ 本月 8 件、成案 6 │  │ 3 Claude 判讀    │  │ 統計與熱點      │  │ 拍照教學        │
│ 小提醒            │  │ 4 確認內容       │  │                 │  │ 法規小幫手      │
└──────────────────┘  │ 5 送出模式       │  └─────────────────┘  │ 備份、照片測試  │
                      └──────────────────┘                       └─────────────────┘
```

### 3.3 各畫面草圖

**首頁**
```
違停檢舉助手
┌──────────────────────────┐
│      ［ 我看到違停 ］       │  ← 最大的按鈕
└──────────────────────────┘
待辦
  ⚠ AAA-0001 忠孝東路四段   今天到期   ［繼續］
  ・ 草稿 2 件
這個月
  送出 8 件｜已舉發 6｜勸導 1｜不舉發 1
小提醒：拍駕駛座，警方才能判斷是「停車」
```

**第 1 步：能不能檢舉**（大按鈕，一題一題問，答完自動下一題）
```
是汽車還是機車？
［ 汽車（四輪以上） ］
［ 機車 ］          → 立刻顯示「不能檢舉，可以打 110」
```

**第 2 步：拍照**
```
拍照清單                         計時 02:41
 ✅ 全景（看得出人行道或斑馬線）
 ✅ 車牌特寫
 ⬜ 駕駛座
 ⬜ 隔 3 分鐘再拍一張    ← 倒數結束時發出提示音
［ 從相簿加入照片 ］
```

**第 3 步：Claude 判讀**
- Claude 自動判斷每張照片是全景、車牌還是駕駛座，不用自己選。
- 有缺的證據直接提醒：「車牌有反光看不清楚，建議靠近再拍一張」。
- 如果你人還在現場，就會想補拍。

**第 4 步：確認內容**（卡片式，每張卡片一個主題）
```
┌ 車輛 ──────────────┐
│ [AAA-0001]  白色自用小客車   自動 ✓ │
│ ⚠ 這台車你 10/02 也檢舉過           │
└──────────────────┘
┌ 地點 ──────────────┐
│ 臺北市 大安區 忠孝東路四段 100 號前 │
│ 來源：附近的舊案件 ／ 照片定位        │
│ ［常用地點］［貼上地圖位置］           │
└──────────────────┘
┌ 時間 ─ 期限 ─────────┐
│ 10/17 14:32    剩 6 天（10/23 前）   │
│ ［加入行事曆提醒］                    │
└──────────────────┘
```

**第 5 步：送出模式**（全螢幕，一次只顯示一欄）
```
臺北市　3 / 12
───────────────
違規日期
2026/10/17
［ 複製 ］
───────────────
［上一欄］        ［下一欄］
```
- 在 Claude 和 Safari 之間切換時，回來就停在下一欄，不會亂掉。
- 最後一欄是「案件編號、查詢密碼」，把官方給的號碼記回來。
